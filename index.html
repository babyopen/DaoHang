组件库

照抄 class 与结构即可复用 · 深浅主题自动适配

基础按钮 .btn
<button class="btn primary">主要</button>
<button class="btn secondary">次要</button>
<button class="btn ghost">取消</button>
<button class="btn danger">删除</button>
<button class="btn text">文字</button>
<button class="btn icon ghost">＋</button>
类型：primary / secondary / ghost / danger / text / icon。
尺寸 .sm / .lg / .block
<button class="btn sm primary">小号</button>
<button class="btn primary">默认</button>
<button class="btn lg primary">大号</button>
<button class="btn primary block">整宽</button>
尺寸：.sm / 默认 / .lg；.block 撑满父容器。
状态 .is-disabled / .is-loading
<button class="btn is-disabled">禁用</button>
<button class="btn is-loading">加载中</button>
禁用：.is-disabled（不拦截点击，需业务自己判断）。加载：.is-loading，自动出转圈，点击应自行忽略。
其它控件
<button class="pill-btn">胶囊</button>
<button class="sheet-close">✕</button>
<div class="switch on"></div>  <!-- JS 用 classList.toggle('on') -->
<span class="swatch" style="background:linear-gradient(140deg,#2b1b6b,#5b3cc4 45%,#00d4ff)"></span>
开关是纯视觉 class，状态由 .on 控制；色卡 .swatch 需自带 background。
复选 / 单选 .checkbox / .radio
<label class="checkbox">
  <input type="checkbox" checked>
  <span class="box"></span><span class="cb-text">已选</span>
</label>

<label class="radio">
  <input type="radio" name="g" checked>
  <span class="box"></span><span class="cb-text">选项 A</span>
</label>

<label class="checkbox is-disabled"><input type="checkbox" disabled><span class="box"></span><span class="cb-text">禁用</span></label>
input 只做视觉隐藏，checked / disabled 原生可用。同组单选取相同 name。
下拉选择 .select（支持搜索）
<div class="select" data-value="">
  <button class="select-trigger" type="button" aria-expanded="false">
    <span class="select-value">请选择</span>
    <svg class="select-chev" viewBox="0 0 24 24"><use href="#i-chev"/></svg>
  </button>
  <!-- 仅数据声明，初始化后会从 DOM 移除 -->
  <div class="select-option" data-value="a">选项 A</div>
  <div class="select-option is-disabled" data-value="b">禁用项</div>
</div>

<script>
var sel = initSelect(document.querySelector('.select'));
sel.onChange(function(v, label){ /* 业务回调 */ });
sel.set('a');   // 程序化赋值
sel.value;      // 读当前值
</script>
面板自动挂到 body、按空间自动上下翻转、支持搜索过滤；Esc 关闭、↑↓ 移动、回车确认。

提示块用于页面内常驻说明，不打断操作。
<div class="notice notice-warn">
  <div class="notice-icon"><svg class="i sm" viewBox="0 0 24 24"><use href="#i-alert"/></svg></div>
  <div class="notice-body">
    <div class="notice-title">注意</div>
    <div class="notice-text">说明文案</div>
  </div>
  <button class="notice-close" type="button"><svg class="i sm" viewBox="0 0 24 24"><use href="#i-x"/></svg></button>
</div>
类型：notice-success / notice-warn / notice-danger / notice-info。关闭按钮可省，省掉即常驻。
标签 .tag
默认标签 主色标签 可关闭 可关闭 
<span class="tag">默认</span>
<span class="tag primary">主色</span>
<span class="tag">可关闭<button class="tag-x" type="button">✕</button></span>
.primary 为主色变体；带 .tag-x 的由 initTagClose() 自动绑定移除动画。
步进器 .stepper / 加载遮罩
<div class="stepper" data-min="1" data-max="99" data-value="3">
  <button class="step-btn" type="button" data-act="minus">−</button>
  <input class="step-val" type="number" value="3" inputmode="numeric">
  <button class="step-btn" type="button" data-act="plus">+</button>
</div>

<script>initStepper(document.querySelector('.stepper'));</script>

<div class="loader" id="loader"></div>
<script>showLoader('正在处理…'); hideLoader();</script>
步进器自动夹紧区间、首尾禁用按钮、长按连续增减。加载遮罩层级 400，高于弹窗与面板。

// 轻提示：ok / err / warn / info
